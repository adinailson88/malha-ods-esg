# Dossiê de literatura, temas e contexto

Material de apoio para o artigo do eixo ODS/ESG, produzido em 03/11/2026 a partir de buscas dirigidas à literatura de indicadores compostos, decisão multicritério, ODS em universidades, gestão de facilities, dados de chamados, validade e consenso de especialistas, contexto regulatório brasileiro e ciência aberta.

| Arquivo | Conteúdo |
|---|---|
| `01_MAPA_TEMATICO.md` | Dez frentes de literatura, o que se sabe, controvérsias, lacunas provisórias com seus limites e temas adicionais |
| `02_REFERENCIAS_VERIFICADAS.md` e `referencias.csv` | 51 entradas com nível de verificação (V1, V2 e V3), DOI quando confirmado e uso previsto no artigo |
| `03_CONTEXTO_BRASIL.md` | Lei 14.133/2021, plano de logística sustentável, acórdãos do Tribunal de Contas da União, normas da ABNT, projeto de política nacional de manutenção predial e estudos nacionais |
| `04_PLANO_DE_LEITURA.md` | Ordem de leitura, ficha mínima, buscas pendentes e itens a conferir |
| `05_ANGULOS_DE_CONTRIBUICAO.md` | Cinco conceitos de artigo, recomendação, arquitetura do argumento e riscos |

Como usar: ler `05` para decidir o recorte, `01` para ver o mapa, `04` para planejar a leitura e `02` como lista de referências a conferir. Atualizar o nível de cada referência para V1 quando for conferida no editor.

Limites: nenhum texto integral foi lido (apenas resumos, registros bibliográficos e páginas institucionais); a busca é dirigida e não sistemática; o estrato Qualis e a política de taxas dos periódicos não foram verificados; as afirmações sobre lacunas dependem da revisão sistemática protocolada em `docs/auditoria/07_REVISAO_DE_LITERATURA.md`.
